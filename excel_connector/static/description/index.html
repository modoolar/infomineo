Odoo to Excel Connector Odoo to Excel Connector

Seamlessly connect your Odoo data to Microsoft Excel.

The Excel Connector for Odoo is a powerful Microsoft add-in that enables seamless integration between Odoo and Excel. This connector is designed to fetch data directly from Odoo in two distinct ways: Table-wise and SQL queries, providing flexibility and control for your data manipulation and reporting needs.

Features:

Microsoft Taskpane Add-in

The Excel Connector operates as a Microsoft Taskpane add-in, giving users a familiar and intuitive interface within Excel.

Table-wise Data Fetching

Easily retrieve data from Odoo tables by selecting from a list of available tables in your Odoo instance. The data is fetched in batches and populated directly into Excel sheets, automatically creating a new worksheet for each table selected.

SQL Query Support

Perform advanced data fetching using SQL queries. Write your own SQL queries and fetch the data, which will be automatically organized and populated in a new Excel worksheet.

Seamless Integration

Connect your Excel to Odoo effortlessly by entering the Odoo server URL and access token. With a few clicks, you can pull in the required data, making it ready for analysis, manipulation, or sharing.

How It Works

Connect to Odoo

Provide your Odoo Backend URL and Access Token in the taskpane interface to establish a connection.

Fetch Data Table-Wise

Select from a list of available tables in Odoo, and the data is fetched and loaded into Excel.

Run SQL Queries

Input your SQL queries directly in the taskpane to fetch specific data from Odoo using SQL.
